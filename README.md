# Лента 850 — выпуски модели

Репозиторий данных. Его пишет только конвейер модели: `latest.json` — указатель на текущий выпуск, `releases/<sha256>.json` — неизменяемые выпуски. Витрина читает выпуск через https://tzi-850-lenta.pages.dev/api/model.

Код модели, книга допущений и описание — https://github.com/ML371KL/temp-zero-inode-850-lenta.
